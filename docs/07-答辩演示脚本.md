# 07 答辩演示脚本（可复现）

> 答辩前准备：确认后端（`python run.py`）与前端（`npm run dev`）均已启动。演示前可删除 `backend/data/pump.db` 后重启后端，系统会**自动建表并初始化种子数据**，保证从干净状态开始、流程可完整复现。

## 演示环境
- 前端：http://localhost:5173
- 后端接口文档：http://localhost:8000/docs
- 演示账号：admin / admin123

---

## 第一幕：登录与系统总览（1 分钟）

1. 打开 http://localhost:5173，展示登录页（预填账号），点击登录。
2. 进入**监控大屏**：
   - 讲解点：暗色科技风大屏，顶部统计（设备总数/运行数/活动告警/累计采集）。
   - 展示 4 个实时仪表盘（最大载荷、电流、冲次、功率）随 WebSocket 数据动态刷新。
   - 展示动态示功图与载荷趋势曲线实时更新。

## 第二幕：技术架构讲解（2 分钟）

1. 打开 http://localhost:8000/docs，展示自动生成的 API 文档，滚动展示四大模块接口。
2. 对照 [01-技术栈与架构.md](01-技术栈与架构.md) 的架构图讲解：
   - 前端 Axios/WS → FastAPI → 服务层 → ORM → SQLite。
   - APScheduler 定时驱动模拟引擎 → 写库 → WebSocket 推送。
3. 强调扩展点：`DataSource` 接口可替换为真实 MQTT 数据源。

## 第三幕：示功图智能诊断（核心亮点，3 分钟）

1. 进入**示功图诊断**页。
2. 点击"气体影响"按钮生成示功图：
   - 展示图形右上角圆弧凸起的典型特征。
   - 自动规则诊断给出"气体影响"结论、置信度与判定依据。
3. 点击"三法对比诊断"：
   - 展示规则决策树、DTW 模板匹配、KNN 机器学习三种方法**结论一致**，体现诊断可靠性。
4. 再点击"供液不足"、"结蜡"等按钮，展示不同工况的图形差异与正确诊断。
5. 对照 [04-算法文档](04-示功图模拟与诊断算法.md) 讲解：
   - 位移简谐模型 + 分段载荷建模生成 6 类工况。
   - 特征参数（填充系数、凹陷深度、凸起高度、载荷基线）如何驱动可解释诊断。
   - 强调规则决策树的可解释性："能讲清为什么判成这个工况"。

## 第四幕：告警闭环（2 分钟）

1. 回到大屏或进入**告警中心**：定时模拟中，非正常工况会触发"工况故障"告警，载荷/电流超限会触发过载/过流告警。
2. 展示告警列表（级别、状态）。
3. 点击"确认"→ 状态变为已确认；点击"清除"→ 状态变为已清除。
4. 讲解点：形成"数据模拟 → 诊断 → 告警 → 确认/清除"的完整业务闭环。

## 第五幕：远程控制与数据报表（2 分钟）

1. 进入**远程控制**页：
   - 点击"远程停止"（二次确认），展示设备状态变化与操作日志。
   - 调节冲次/载荷上限参数并保存，展示参数更新。
   - 再次点击"远程启动"恢复运行。
2. 进入**统计报表**页：
   - 展示工况分布饼图、载荷趋势、统计卡片。
   - 点击"导出 CSV"/"导出 Excel"，展示文件下载。
3. 进入**历史数据**页：筛选设备与时间，展示历史数据表，点击行查看示功图。

## 第六幕：总结与分工（1 分钟）

1. 对照 [06-分工与里程碑.md](06-分工与里程碑.md)，每位成员讲解自己负责的模块。
2. 总结技术亮点：
   - 全栈架构、实时 WebSocket 推送。
   - 数学建模的示功图仿真 + 三法融合智能诊断（可解释 + ML）。
   - 完整业务闭环（监测-诊断-告警-控制-报表）。
   - 教学权衡（SQLite、模拟数据）与生产扩展路径（时序库、真实设备接入）。
