# 05 前端页面设计

前端为 Vue 3 + TypeScript 单页应用，主布局为左侧导航 + 顶栏 + 内容区（`components/AppLayout.vue`）。

## 页面清单

| 路由 | 页面组件 | 展示内容 |
|---|---|---|
| `/login` | Login.vue | 登录表单，预填演示账号 |
| `/dashboard` | Dashboard.vue | 暗色科技风监控大屏：设备/告警/采集统计、4 个实时仪表盘、动态示功图、载荷趋势、告警滚动 |
| `/realtime` | RealtimeMonitor.vue | 9 项实时指标卡片、动态示功图、载荷趋势（WebSocket 刷新）、设备切换 |
| `/dynamo` | DynamoAnalysis.vue | 工况生成按钮组、示功图（实测+标准模板虚线对比）、诊断结论卡片、特征参数表、三法对比表 |
| `/history` | HistoryData.vue | 设备/时间筛选、历史数据表、点击行查看示功图 |
| `/reports` | Reports.vue | 统计卡片、工况分布饼图、载荷趋势、CSV/Excel 导出 |
| `/control` | Control.vue | 启停按钮（二次确认）、参数调节表单、控制日志 |
| `/devices` | DeviceManage.vue | 设备台账增删改查 |
| `/alarms` | Alarms.vue | 告警统计、列表过滤、确认/清除 |

## 核心复用组件

| 组件 | 作用 |
|---|---|
| `DynamoChart.vue` | ECharts 示功图闭合曲线，填充渐变、Pmax/Pmin 标注、诊断工况标签、可叠加标准模板虚线。监测页/诊断页/大屏共用 |
| `TrendChart.vue` | 多指标趋势曲线 |
| `GaugeCard.vue` | 载荷/电流/冲次/功率仪表盘卡片 |
| `ConditionTag.vue` | 工况彩色标签 |
| `DeviceSelector.vue` | 设备下拉选择器（联动全局 store） |
| `AlarmBadge.vue` | 告警角标 |

## 核心组合式函数

`composables/useRealtime.ts`：统一管理 WebSocket 连接、断线重连（3 秒）、数据订阅。各页面调用时传入 `deviceId` 的 getter 与消息回调，实现实时数据驱动页面刷新。

## 状态管理（Pinia）

- `useDeviceStore`：设备列表、当前选中设备
- `useRealtimeStore`：最新实时数据、连接状态、历史缓存（最多 200 条）
- `useUserStore`：登录用户与 token

## 请求封装

`api/request.ts`：Axios 拦截器自动携带 Bearer token、解包统一响应 `{code,message,data}`、错误提示。`api/index.ts` 按模块导出所有接口调用。
