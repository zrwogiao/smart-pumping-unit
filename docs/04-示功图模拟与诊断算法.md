# 04 示功图模拟与诊断算法

这是本项目的技术核心与答辩亮点，采用"数学建模生成 + 可解释诊断 + 机器学习对比"三层设计。核心文件：
- `backend/app/services/simulator.py` —— 数据模拟引擎
- `backend/app/services/features.py` —— 特征提取
- `backend/app/services/diagnosis_service.py` —— 三层诊断
- `backend/app/services/constants.py` —— 工况字典

## 1. 示功图数据模拟

### 1.1 位移模型
一个冲程周期取 100 个采样点，位移按简谐运动：
- 上冲程：`s(t) = 0.5 × (1 − cos(2πt))`，s 从 0 → 1
- 下冲程：s 从 1 → 0
- 上下冲程拼接成闭合曲线

### 1.2 载荷模型
载荷以归一化区间 [0,1] 的分段折线控制点建模（0=最小载荷，1=最大载荷），满足 `np.interp` 横坐标递增要求：
- 上冲程载荷曲线 `P_up(s)`：悬点上行，载荷高（接近 Pmax）
- 下冲程载荷曲线 `P_down(s)`：悬点下行，载荷低（接近 Pmin）
- 实际载荷 = Pmin + p_norm × span

参考值 Pmin=25 kN，span=55 kN（Pmax=80 kN）。

### 1.3 六类工况的几何特征

| 工况 key | 中文名 | 关键几何特征 | 建模方式 |
|---|---|---|---|
| normal | 正常 | 饱满平行四边形 | 上下载荷差稳定，无异常 |
| pump_leak | 泵漏失 | 变瘦、面积减小 | 上下冲程载荷线靠拢，span 缩小 |
| insufficient_liquid | 供液不足 | 底部刀把状下凹 | 下冲程接近下死点时载荷骤降走平 |
| gas_affected | 气体影响 | 右上角圆弧凸起 | 上冲程末段叠加圆弧抬升 |
| wax | 结蜡 | 整体上移、变宽、毛刺 | 上下载荷整体抬高 + 增大噪声 |
| rod_parted | 抽油杆断脱 | 扁平贴底 | 载荷整体极低，载荷差极小 |

叠加小幅高斯噪声并用 Savitzky-Golay 平滑，使每次生成的示功图略有差异但同类工况形状稳定。

## 2. 特征提取（features.py）

预处理：Savitzky-Golay 平滑去噪。核心特征：

| 特征 | 含义 | 计算 |
|---|---|---|
| Pmax / Pmin | 最大/最小载荷 | 载荷序列极值 |
| span | 载荷差 | Pmax − Pmin |
| delta_p | 上下冲程平均载荷差 | 上冲程均值 − 下冲程均值 |
| area | 示功图面积 | 鞋带公式 ∮P·ds |
| fill | 填充系数 | area / (位移跨度 × span) |
| pbase | 载荷基线 | (Pmax + Pmin) / 2，结蜡时上移 |
| notch_depth | 底部凹陷深度 | 下冲程前段中位数 − 尾部最小值 |
| bulge_height | 右上凸起高度 | 上冲程末段最大值 − 中段中位数 |

## 3. 三层诊断引擎（diagnosis_service.py）

### 第一层：规则决策树（主，可解释）
基于实测校准的决策树（顺序体现优先级）：

1. `span < 12` → **抽油杆断脱**
2. `span < 35` → **泵漏失**
3. `bulge / span > 0.15` → **气体影响**
4. `notch / span > 0.13` → **供液不足**
5. `pbase > 60` → **结蜡**
6. 其余 → **正常**

输出工况 + 置信度 + **判定依据（evidence）** + 处理建议。可解释性是教学答辩的核心优势——能讲清"为什么判成这个工况"。

### 第二层：模板匹配（对比兜底）
维护标准工况模板库（无噪声生成），用**动态时间规整（DTW）**计算输入示功图与各模板归一化载荷曲线的相似度，取距离最小者。用归一化后的距离比换算置信度。

### 第三层：机器学习分类器（进阶）
用模拟引擎批量生成带标签样本（每工况 60 张），提取特征训练 **KNN（n_neighbors=5，距离加权）** 分类器（`predict_proba` 给出置信度）。模型延迟训练、全局缓存复用。模拟引擎天然提供充足标注数据，是模拟方案的独特优势。

### 统一输出
`diagnose(disp, load, method)` 统一返回：
```
{ condition, label, confidence, method, features, suggestion, evidence }
```
`method='all'` 时返回三法对比 `{ features, results: { rule, template, ml } }`，供前端诊断页展示对比表。

## 4. 告警判定（alarm_service.py）
定时检查实时监测数据：
- `max_load > max_load_limit` → 过载（critical）
- `current > current_limit` → 过流（warning）
- 诊断出非正常工况 → 工况故障（warning）
- 同类 active 告警去重，避免刷屏

## 5. 实测准确率

| 方法 | 准确率 |
|---|---|
| 规则决策树 | 100%（180/180） |
| 模板匹配 DTW | 90%（54/60） |
| 机器学习 KNN | 100%（120/120） |
