# 02 数据库设计

数据库为 SQLite，共 7 张表，均含 `id`（主键）与 `created_at`（除特别说明）。ORM 定义位于 `backend/app/models/`。

## 2.1 users 用户表
| 字段 | 类型 | 说明 |
|---|---|---|
| username | VARCHAR(50) UNIQUE | 登录名 |
| password_hash | VARCHAR(128) | PBKDF2 密码哈希 |
| real_name | VARCHAR(50) | 姓名 |
| role | VARCHAR(20) | admin / operator / viewer |
| is_active | BOOLEAN | 是否启用 |

## 2.2 devices 设备表
| 字段 | 类型 | 说明 |
|---|---|---|
| device_code | VARCHAR(50) UNIQUE | 设备编号（PUMP-001） |
| device_name | VARCHAR(100) | 设备名称/井号 |
| well_location | VARCHAR(100) | 井位/区块 |
| status | VARCHAR(20) | running / stopped / fault |
| stroke_length | FLOAT | 冲程 S（m） |
| stroke_rate | FLOAT | 冲次 N（次/min） |
| pump_depth | FLOAT | 泵挂深度（m） |
| max_load_limit | FLOAT | 载荷上限告警阈值（kN） |
| current_limit | FLOAT | 电流告警阈值（A） |
| last_heartbeat | DATETIME | 最后心跳 |

## 2.3 realtime_data 实时监测表（时序）
| 字段 | 类型 | 说明 |
|---|---|---|
| device_id | INTEGER FK,索引 | 设备 ID |
| timestamp | DATETIME,索引 | 采集时间 |
| max_load / min_load | FLOAT | 最大/最小载荷（kN） |
| displacement | FLOAT | 当前位移（m） |
| current / voltage | FLOAT | 电流（A）/电压（V） |
| stroke_rate / stroke_length | FLOAT | 冲次/冲程 |
| power | FLOAT | 功率（kW） |

## 2.4 dynamo_cards 示功图表
| 字段 | 类型 | 说明 |
|---|---|---|
| device_id | INTEGER,索引 | 设备 ID |
| timestamp | DATETIME,索引 | 采集时间 |
| source | VARCHAR(20) | simulated / real |
| condition_hint | VARCHAR(30) | 模拟真值工况（验证诊断准确率用） |
| displacement / load | TEXT | 位移/载荷序列 JSON（100 点） |
| max_load / min_load | FLOAT | 最大/最小载荷 |
| area | FLOAT | 示功图面积（有效功） |

## 2.5 diagnosis_results 诊断结果表
| 字段 | 类型 | 说明 |
|---|---|---|
| dynamo_id / device_id | INTEGER | 示功图 ID / 设备 ID |
| condition / condition_label | VARCHAR | 工况 key / 中文名 |
| confidence | FLOAT | 置信度 0~1 |
| features_json | TEXT | 特征参数快照 |
| method | VARCHAR(20) | rule / template / ml |
| suggestion | TEXT | 处理建议 |
| diagnosed_at | DATETIME | 诊断时间 |

## 2.6 alarms 告警表
| 字段 | 类型 | 说明 |
|---|---|---|
| device_id | INTEGER,索引 | 设备 ID |
| alarm_type | VARCHAR(30) | overload / overcurrent / condition_fault / offline |
| level | VARCHAR(10) | info / warning / critical |
| message | VARCHAR(255) | 告警内容 |
| value | FLOAT | 触发值 |
| status | VARCHAR(15) | active / acknowledged / cleared |
| triggered_at | DATETIME | 触发时间 |
| acknowledged_by / acknowledged_at | INTEGER / DATETIME | 确认人/时间 |

## 2.7 control_logs 控制日志表
| 字段 | 类型 | 说明 |
|---|---|---|
| device_id | INTEGER,索引 | 设备 ID |
| command | VARCHAR(30) | start / stop / set_params |
| params_json | TEXT | 参数变更内容 |
| operator_id | INTEGER | 操作人 |
| result | VARCHAR(20) | success / failed |
| executed_at | DATETIME | 执行时间 |

> 工况字典采用常量枚举实现（`backend/app/services/constants.py` + 前端 `types`），不单独建表。
